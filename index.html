Rankings Calculator

Consolidated trade values, normalized so no single source skews the average. The small number next to each value is how many sites it's based on. With 5, one outlier opinion gets balanced out by the rest; with 2 or fewer, there's little to balance it against — treat those with extra caution, since it isn't really a consolidated number at that point, just one or two sites' opinions that could easily be skewing it.

Sources: Yahoo, CBS Sports, FantasyPros, RotoStreetJournal, USA Today — each site's values are normalized before blending, so no one source's scale dominates the average.
